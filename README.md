# أذكار المسلم — جاهز للنشر على GitHub Pages وVercel

هذا مشروع ويب ثابت (HTML وCSS وJavaScript) مع دعم PWA وService Worker. لا يحتاج إلى Node.js أو قاعدة بيانات أو خادم خلفي حتى تعرض الواجهة الأساسية.

## محتويات المشروع
- `index.html`: الصفحة الرئيسية للتطبيق.
- `style.css`: التنسيقات والتصميم.
- `app.js`: وظائف التطبيق.
- `sw.js`: تخزين ملفات التطبيق الأساسية مؤقتًا لدعم العمل دون اتصال بعد أول زيارة ناجحة، مع صفحة احتياطية عند انقطاع الشبكة.
- `manifest.webmanifest` و`icon.svg`: إعدادات التثبيت والأيقونة.
- `golden-mushaf.webp` و`golden-mushaf.png`: صور شاشة البداية.
- `preview.html`: صفحة المعاينة الموجودة ضمن النسخة الأصلية.
- `.github/workflows/pages.yml`: نشر تلقائي على GitHub Pages.
- `vercel.json`: إعدادات رؤوس التخزين المؤقت وملف manifest.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط الملف على جهازك، ثم ارفع **كل محتويات المجلد الناتج** إلى جذر المستودع مباشرة؛ لا ترفع ملف ZIP وحده ولا ترفع مجلدًا متداخلًا يحتوي الملفات.
3. اجعل اسم الفرع الرئيسي `main`، ثم ادفع الملفات إليه.
4. افتح إعدادات المستودع: **Settings → Pages**.
5. في **Build and deployment** اختر **GitHub Actions**.
6. افتح تبويب **Actions** وانتظر انتهاء مهمة `Deploy to GitHub Pages`.
7. سيظهر رابط الموقع في إعدادات Pages.

أي تحديث ترفعه إلى فرع `main` سيؤدي إلى نشر نسخة جديدة تلقائيًا.

## النشر على Vercel
1. ادخل إلى Vercel وسجّل الدخول بحسابك.
2. اختر **Add New → Project** ثم اربط مستودع GitHub الذي رفعت إليه الملفات.
3. اجعل **Root Directory** هو جذر المشروع.
4. اترك إعدادات البناء دون أمر Build ودون مجلد إخراج مخصص؛ المشروع ملفات ثابتة.
5. اضغط **Deploy**. سيعيد Vercel النشر تلقائيًا عند كل تحديث للمستودع.

## تجربة محلية
يمكن فتح `index.html` لمعاينة الواجهة، لكن ميزات PWA وService Worker والإشعارات تحتاج إلى خادم محلي أو HTTPS. لتشغيل خادم محلي إذا كان Python مثبتًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## زر «ابدأ رحلتك»
زر شاشة البداية يزيل شاشة الترحيب ويُظهر الصفحة الرئيسية مباشرة. أُضيف له إجراء احتياطي داخل HTML حتى يعمل حتى لو تعطل تحميل JavaScript الرئيسي.

## حدود العمل دون إنترنت
- ملفات الواجهة الأساسية تُخزّن مؤقتًا بعد أول تحميل ناجح من خلال Service Worker.
- بعض الأقسام التي تعتمد على خدمات خارجية، مثل فهرس القرآن والتفاسير وقائمة القراء أو بث الصوت، قد تحتاج إلى الإنترنت عند طلب بيانات لم تُحفظ مسبقًا.
- ملفات الصوت الكاملة ليست مضمنة في المشروع، لذلك لا يمكن ضمان تشغيل كل التلاوات والأذان دون اتصال.
- الإشعارات ومواقيت الصلاة تعتمد على دعم المتصفح وأذوناته؛ ولا يضمن هذا المشروع تنبيهًا مستمرًا بعد إغلاق المتصفح بالكامل.
- GitHub Pages وVercel يستضيفان الملفات؛ لا يضيف هذا الإعداد قاعدة بيانات أو لوحة تحكم أو وظائف خلفية.

## ملاحظة
هذا إعداد للنشر والاستضافة فقط، ولم تتم إضافة لوحة تحكم أو خادم خلفي. راجع محتوى النصوص الدينية ومصادرها قبل النشر العام.
